# Montreal French Flashcards

A mobile-friendly flashcard site for common English/French travel phrases.

## Features

- Choose whether French or English appears first
- Tap the card to flip between the phrase and translation
- Play the currently displayed phrase with the browser's speech audio
- Jump between all 25 phrase cards

## Commands

```bash
npm install
npm run dev
npm run build
```

The selected front language is saved on the device with `localStorage`.
